# Reglas permanentes del proyecto

Estas reglas son obligatorias para toda contribución:

1. No inventar endpoints ni estructuras de datos. Antes de implementar una
   integración, verificarla contra documentación o respuestas oficiales.
2. Usar exclusivamente fuentes oficiales.
3. Preservar siempre, sin modificaciones, el valor original recibido desde la
   fuente, aunque además se almacene una representación normalizada.
4. Toda información publicada debe indicar su fuente de forma verificable.
5. No interpretar una ausencia o una votación como conducta incorrecta.
6. No agregar scores, rankings ni clasificaciones sin una decisión explícita
   posterior que cambie el alcance.
7. Ejecutar los tests y comprobaciones aplicables antes de finalizar cada tarea.

La V0 se rige además por `docs/scope-v0.md`. No ampliar ese alcance de manera
implícita.
